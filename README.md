# Horizon launcher for Arch Linux

Community AUR package for [Horizon](https://github.com/horizon-rust/horizon).

```sh
paru -S horizon-launcher-bin
# or: yay -S horizon-launcher-bin
```

Launch **Horizon** from the applications menu or run `horizon-launcher`.

Requires a Vulkan driver. Preparing game resources needs your own Minecraft:
Java Edition installation and Java 25 (`jdk25-openjdk`).
